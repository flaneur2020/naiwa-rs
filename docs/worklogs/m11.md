# M11 — one MoE provider

Status: **done**.
Parent: [m10.md](m10.md).

## Changes

- `--cpu-moe` now requires `--expert-cache-gb`: clap enforces the pair, and
  `base_builder` still returns a context error if a caller bypasses parsing.
- Remove `CpuMoeProvider`. `install_cpu_moe` always installs
  `GpuCacheMoeProvider`; when a layer gets no cache slots, is the MTP head, or
  is on a CPU device, the provider returns `CpuExperts` as before.
- `provider_gpu.rs` naming is gone: the file is `provider.rs`.
  `GpuCacheMoeProvider` keeps its name.
- `cpu.rs` is now only `CpuExperts` + `fused_decode` + `attach_prefill`; it no
  longer owns a provider.
- `layer.rs` → `cached_layer.rs`.
