# M15 — doorbell call-site simplification

Status: **done**.
Parent: [m14.md](m14.md).

## Changes

- `TopkDoorbell` owns its host sequence and exposes one round trip:
  `publish_and_read(ids, weights, n) -> (ids, weights)`.
  `LayerState.doorbell_seq` is gone; `publish` / `wait_and_read` are private.
- `LookaheadChannel::read(last_seq, n)` owns the stale check, `wait_publish`, and
  the `consumed` update. `next_seq` / `consumed` / `chan` are private; `preload`
  only calls `read`.
- `GateSet::publish_stream` / `publish_stream_max` / `wait` take `(layer, kind)`
  and hide `sync_id`; production no longer calls `sync_id` or `gate`.
- `ResultDoorbell` is unchanged: `executor::cuda::Channel` already owns its seq.
